What this check covers, and what it does not

It recomputes each stratum's correlation, cell and attempt counts, the design effect and effective sample size at 20 attempts per cell, both zero-failure bounds, and the family merge with its interval. Those are the deterministic parts.

It does not recompute the percentile interval that comes from resampling cells, and it does not check the newer columns mixed_fields and rho_excl_constant. The Python verifier does all of that; this page is the quick check, and the receipt says which is which.

Reading the result. A pass means the summary follows from the table under the published rules. It does not mean the evaluation measured what it claims, and it does not mean the attempts are complete.

If you want a receipt someone else can re-run

Run python3 tools/verify_public.py --release <id> in a clone, or fork the repository and run the Reproduce a release workflow. Both produce the same JSON shape as the button above, with file hashes and the tool version. Open an issue with the receipt attached; it gets recorded in governance/verification_partners.csv.
