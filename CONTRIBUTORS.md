# Contributors

Contributions are recorded here and, for code and data changes, in `git log`. Historical
commits are not re-attributed: rewriting them would invalidate tags, release hashes and
deposited bytes. Work done before a person had commit access is recorded in
`contributions/`, with the evidence that survives.

## Rules

- A contributor is credited for what they did, not for access: the ledger names the work,
  the file or commit where it landed, and the hash of the original material.
- Commit author and commit signer are separate fields. The signer attests to the object,
  not to authorship; both are recorded.
- Co-authorship on a joint change uses the `Co-authored-by:` trailer.
- Authorship in `CITATION.cff` applies from the release in which it is added; it is not
  backdated to earlier releases.
